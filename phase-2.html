Where Phase 1 ended

Twelve lessons, one arc — complete.

Turing → symbolic AI → its collapse → learning from data → perceptron → backprop → deep learning → embeddings → sequences → attention → LLMs → agents. All twelve done 2026-06-21, written up in The Journey to AI Agents. Every leap fixed the wall the last idea hit.

Then the roadmap for what comes next sat untouched for eleven weeks. That stall is the first thing this phase fixes.

Why the last plan stalled

Plan shape, not motivation.

Defect 1 — the budget was fiction

4 hrs/day, every day, for a working full-stack engineer. One missed day made the schedule wrong — and a wrong schedule gets abandoned, not adjusted. Fix: weekend-sized units at the real budget, ~9 hrs per weekend.

Defect 2 — items were topics, not sessions

"A3. Positional encoding ⬜" has no start, no end, no artifact — no way to be wrong. "Understood" is unfalsifiable, so nothing ever got ticked. Fix: every weekend names an artifact and a four-part gate.

Defect 3 — no forcing function

Phase 1 worked because every lesson shipped a committed writeup — git history was the progress. The concept roadmap dropped that. Fix: commit every Sunday; a missed weekend gets logged, never hidden.

The unit of work

One weekend, one concept, one artifact.

The gate — definition of done

It runs · you broke it (one failure the theory predicts) · beginner test (plain-language paragraph) · it's committed. All four, or the box stays empty.
