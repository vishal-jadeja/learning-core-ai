# Concept writeups

One file per closed concept, in the `AI_Learning_Journey.md` voice:
*what did the last step leave broken → the idea that fixes it → why it matters* —
plus the **beginner test** paragraph (plain language, no jargon) and a link to the
runnable artifact in `../experiments/`.

Naming: `A1-tokenization.md`, `A2-sampling.md`, … `D2-diffusion.md`.

A writeup lands here only when the weekend's gate passes (see
[PHASE_2_CONCEPTS.md](../PHASE_2_CONCEPTS.md)): it runs · you broke it ·
beginner test · committed.
